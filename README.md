# FlowStage Runbook AI

Create a modern premium SaaS landing page and web app called FlowStage.

FlowStage is an AI-powered event operations assistant that generates professional run-of-show documents for conferences, summits, corporate events, and panels.

The design should feel minimal, premium, operational, and trustworthy. Use a clean white, charcoal, muted navy, and soft gray color palette with subtle blue accents. Avoid flashy startup aesthetics.

The product should include:

 A landing page with:

 hero section

 feature highlights

 sample run-of-show preview

 CTA button

 A generator form page where users can input:

 event name

 event type

 event date

 sessions

 speakers

 moderators

 networking breaks

 sponsor mentions

 AV requirements

 An output page displaying a polished professional run-of-show document with:

 timeline

 speaker transitions

 moderation notes

 AV reminders

 backstage coordination notes

 sponsor mentions

 operational reminders

Use modern typography and a clean B2B SaaS layout inspired by Notion and Linear.
